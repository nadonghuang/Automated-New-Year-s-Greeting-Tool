# 添加好友功能实现计划

## 需求分析
在好友名单页面（ContactList）中添加一个"添加好友"按钮，允许用户在已有联系人列表后继续添加新的好友。

## 实现方案

### 1. 修改 ContactList 组件
**文件**: `frontend/components/ContactList.tsx`

- 添加 `onAddContact` 回调属性
- 在搜索框旁边添加一个"+"按钮（添加好友按钮）
- 点击按钮后弹出一个模态框，用户可以输入好友名称

### 2. 修改主页面
**文件**: `frontend/app/page.tsx`

- 添加 `handleAddContact` 函数，处理添加新好友的逻辑
- 将该函数传递给 `ContactList` 组件
- 新好友会被合并到现有联系人列表中（去重处理）

### 3. 创建添加好友模态框组件
**文件**: `frontend/components/AddContactModal.tsx`（新建）

- 设计一个简洁的模态框界面
- 包含好友名称输入框
- 支持添加备注（可选）
- 确认/取消按钮

## UI 设计
- 按钮位置：搜索框右侧
- 按钮样式：与整体设计风格一致（红色渐变 + 金色边框）
- 模态框：玻璃态效果，圆角设计，与现有 UI 风格统一
