# 修复计划

## 一、后端修复

### 1.1 更新依赖
- `backend/requirements.txt`: 添加 `slowapi` 和 `itsdangerous` 用于速率限制和会话管理

### 1.2 配置文件改进
- `backend/config.py`: 支持环境变量覆盖日志配置

### 1.3 异常处理改进
- `backend/generator.py`:
  - 改进 `validate_key()` 方法，返回详细错误信息
  - 替换裸 `except` 为具体异常类型
  - 改进日志记录，避免泄露敏感信息

### 1.4 API 核心修复
- `backend/main.py`:
  - 修复 CORS 配置，限制允许的来源
  - 移除全局 `generator_instance`，使用依赖注入
  - 添加速率限制中间件

  - 添加统一错误处理中间件
  - 添加请求大小限制
